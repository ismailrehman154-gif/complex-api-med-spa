# UV Checker (Med Spa App)

Built for the bootcamp's "complex API" project: pick a med spa treatment and enter a location, and it pulls the live UV index and gives aftercare guidance for that treatment.

![UV Checker screenshot](screenshot.jpg)

The interesting bit is combining the two sides: live UV data from a weather API on one hand, treatment-specific aftercare rules on the other, merged into one clean result card.

Vanilla JavaScript with fetch.
